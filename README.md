# IMS Committee Volunteers — GitHub Pages

A minimal, marketing-style volunteer recruitment website for the
Institute of Management Sciences, University of Lucknow.

## Files

- `index.html` — website structure/content
- `style.css` — responsive design and animations
- `script.js` — scroll reveal + progress animation
- `assets/university-logo.jpg` — University of Lucknow logo

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Save.
6. GitHub will generate your Pages URL.

Keep `index.html` in the repository root.
